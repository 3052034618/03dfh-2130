## 1. 产品概述

封闭式漫画弹幕反馈阅读器，面向漫画作者和工作室在连载上线前的小范围内测场景。作者上传草稿章节后生成私密试阅链接，受邀读者在指定画面区域留下弹幕式反馈，帮助作者精准定位问题并高效迭代创作。

- 核心价值：将开放式评论转化为定位精准、分类清晰的分镜级反馈，显著提升漫画创作迭代效率
- 目标用户：漫画作者、漫画工作室、专业编辑、漫画助手、核心粉丝群

## 2. 核心功能

### 2.1 用户角色

| 角色 | 进入方式 | 核心权限 |
|------|----------|----------|
| 作者 | 账号登录 | 上传章节、生成试阅链接、查看所有反馈、标记处理状态、上传修订版本 |
| 编辑 | 专属链接 | 阅读漫画、发布弹幕反馈、查看同角色反馈 |
| 助手 | 专属链接 | 阅读漫画、发布校对反馈、查看同角色反馈 |
| 核心粉丝 | 专属链接 | 阅读漫画、发布读者反馈、仅查看自己的反馈 |

### 2.2 功能模块

1. **作者工作台**：作品列表、章节管理、试阅链接生成、反馈总览
2. **漫画阅读器**：分镜浏览、区域弹幕、身份标识
3. **反馈编辑器**：类型选择、画面圈选、内容输入
4. **反馈看板**：身份分层筛选、类型统计、状态标记
5. **版本对照**：新旧页面对比、弹幕位置保留、处理状态流转

| 页面名称 | 模块名称 | 功能描述 |
|-----------|-------------|---------------------|

## 3. 核心流程

### 3.1 作者发布试阅流程

作者登录工作台 → 创建作品并上传章节图片 → 系统生成三种角色的试阅链接 → 作者将链接分享给对应人员 → 受邀者通过链接直接进入阅读页

```mermaid
flowchart LR
    A["作者登录工作台"] --> B["创建作品"]
    B --> C["上传章节页面"]
    C --> D["生成角色试阅链接"]
    D --> E["分享给编辑/助手/粉丝"]
    E --> F["受邀者链接进入阅读"]
```

### 3.2 读者发布弹幕反馈流程

读者通过链接进入阅读页 → 浏览漫画时发现需反馈之处 → 点击工具栏选择反馈类型 → 在画面上圈选具体区域 → 输入反馈文字 → 提交后弹幕标记出现在对应位置

```mermaid
flowchart LR
    A["进入阅读页"] --> B["浏览漫画"]
    B --> C["选择反馈类型"]
    C --> D["圈选画面区域"]
    D --> E["输入反馈内容"]
    E --> F["提交弹幕"]
    F --> G["标记点显示在画面上"]
```

### 3.3 作者查看与处理反馈流程

作者进入反馈看板 → 按角色/类型筛选反馈 → 点击反馈跳转至对应画面位置 → 查看弹幕详情 → 标记处理状态 → 上传修订版本 → 在对照视图中确认处理

```mermaid
flowchart LR
    A["进入反馈看板"] --> B["按角色筛选"]
    B --> C["按类型筛选"]
    C --> D["查看弹幕详情"]
    D --> E["标记处理状态"]
    E --> F["上传修订页面"]
    F --> G["新旧版本对照"]
```

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深空灰 `#1a1a1e` 作为背景，漫画纸白 `#f5f1e8` 作为内容底色，赭红 `#c2410c` 作为强调色
- **辅助色**：五种反馈类型各有专属颜色标识（看不懂-蓝、节奏慢-紫、笑点有效-黄、角色可爱-粉、画面问题-红）
- **按钮风格**：扁平圆角按钮，悬停有轻微上浮和发光效果
- **字体**：标题用具有设计感的衬线字体，正文用清晰易读的无衬线字体
- **布局风格**：卡片式布局，阅读器为全屏沉浸式体验，工作台为侧边导航+内容区双栏布局
- **视觉元素**：弹幕标记点采用脉冲呼吸动画，悬停展开时带弹性动效

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|-----------|-------------|-------------|
| 作者工作台 | 作品卡片 | 封面缩略图、标题、章节数、反馈数徽标、三种颜色的角色反馈统计条 |
| 作者工作台 | 链接生成器 | 卡片式设计，三个角色标签页，二维码+链接复制按钮，有效期选择 |
| 漫画阅读器 | 分镜浏览区 | 深色沉浸式背景，漫画页面居中显示，间距均匀，滚动平滑 |
| 漫画阅读器 | 弹幕叠层 | 彩色圆形标记点+脉冲光圈，悬停弹出气泡卡片，显示类型、角色、内容 |
| 反馈编辑器 | 类型选择器 | 横向排列的彩色标签按钮，选中态有下沉阴影 |
| 反馈编辑器 | 区域圈选 | 半透明彩色遮罩，四角可拖拽调整，虚线边框闪烁 |
| 反馈看板 | 筛选标签 | 胶囊形标签组，选中态填充强调色 |
| 反馈看板 | 反馈列表项 | 左侧缩略预览圈选区域，中间类型标签+内容摘要，右侧角色徽章+状态标记按钮 |
| 版本对照 | 双栏对比 | 可拖动分割线，左右页面同步缩放，弹幕带连线指示 |

### 4.3 响应式设计

- 桌面端优先设计（1280px及以上），工作台为双栏布局
- 平板端（768px-1279px）：工作台侧边栏折叠为图标导航
- 移动端（768px以下）：阅读器单列全屏展示，反馈操作简化为底部浮动按钮

## 5. 交互细节

### 5.1 弹幕标记点
- 默认显示为彩色圆点，伴随呼吸脉冲动画吸引注意
- 鼠标悬停时扩大为气泡，显示类型、反馈者角色和内容摘要
- 点击时弹出完整反馈卡片，可查看全部内容和操作

### 5.2 区域圈选
- 进入圈选模式后，鼠标变为十字光标
- 拖拽起始点至结束点形成半透明彩色遮罩区域
- 区域四周有拖拽控制点，可精细调整范围
- 支持 ESC 键取消，Enter 键确认

### 5.3 版本对照
- 左右双栏显示旧版和新版页面
- 旧版弹幕位置保留，新版上显示虚线框指示原位置
- 可通过中间分割线调整两栏宽度比例
- 弹幕可一键标记已处理/暂不改
